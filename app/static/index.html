1. Send a webhook

This does exactly what a payment provider (like Razorpay) would do.

How it works

  1. The webhook is saved to the database first, then the service answers 202 Accepted straight away.
  2. A background worker picks it up and simulates the payment work for 30 seconds.
  3. The status flips from PROCESSING to PROCESSED.
  4. Sending the same transaction ID again never creates a second transaction.
